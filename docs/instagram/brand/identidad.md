# HISTORIA EN PIXEL — identidad de marca

## 1. Posicionamiento

**HISTORIA EN PIXEL** convierte episodios, personajes, conflictos y mapas de la historia en piezas visuales inspiradas en videojuegos de estrategia, RPG y pantallas de selección.

**Promesa:** aprender historia a través de una interfaz que parece un videojuego, sin confundir la representación lúdica con la valoración moral de los hechos.

**Arquitectura de marca:**
- Marca madre: `HISTORIA EN PIXEL`
- Series: `DICTATORS ARENA`, `CAMPAIGN MAP`, `FICHA JUGABLE`, `HISTORIA COMO MAPA`
- Assets: identificados por `HP-###`

## 2. Personalidad

- Estratégica
- Histórica
- Visual
- Directa
- Curiosa
- Crítica cuando el tema lo exige

Evitar que la marca se perciba como una cuenta de propaganda, admiración política o glorificación de violencia.

## 3. Dirección visual

### Paleta base

| Rol | Color | Uso |
|---|---|---|
| Fondo | `#0B0B0D` | Negro carbón, UI y fondos principales |
| Primario | `#C62828` | Alertas, facciones, títulos y énfasis |
| Secundario | `#D4AF37` | Stats, bordes, logros y acentos premium |
| Texto | `#F1EDE2` | Texto principal sobre fondo oscuro |
| Neutro | `#6E6A63` | Texto secundario, metadatos y divisores |

Los colores son una guía de sistema; cada serie puede añadir un color identificador sin romper la paleta base.

### Tipografía

Prioridad:
1. Fuente display pixel/arcade para títulos cortos.
2. Sans serif condensada para UI, estadísticas y etiquetas.
3. Sans serif altamente legible para textos históricos y captions.

Regla: **pixel art para identidad; legibilidad moderna para información.**

### Elementos gráficos

- Marcos tipo HUD.
- Barras de vida/estadísticas como metáfora visual.
- Iconos simples de mapa, ejército, economía, diplomacia y territorio.
- Divisores de 1–3 px.
- Texturas discretas de CRT/pixel solo cuando no reduzcan la legibilidad.
- Capturas/ilustraciones tratadas como piezas de un videojuego ficticio, no como material propagandístico.

## 4. Logo y avatar

Concepto recomendado:
- Wordmark `HISTORIA EN PIXEL` en dos líneas o bloque compacto.
- Monograma `HP` como avatar secundario.
- Marco cuadrado inspirado en una interfaz de selección.
- Evitar sobrecargar el avatar con personajes o texto pequeño.

`HP-013` y `HP-017` funcionan como referencias visuales iniciales, pero se consideran conceptos de branding, no el manual definitivo.

## 5. Sistema de composición

### Portada
`[SERIE]` → `[TEMA]` → `[GANCHO]`

### Cuerpo
`[VISUAL]` + `[DATO CLAVE]` + `[MECÁNICA DE JUEGO / METÁFORA]`

### Cierre
`[CONTEXTO HISTÓRICO]` → `[CONSECUENCIA]` → `HISTORIA EN PIXEL`

## 6. Regla editorial central

La interfaz puede decir **"ataque 90"** como recurso de diseño, pero nunca debe presentarse como un dato histórico objetivo. Las estadísticas son interpretaciones editoriales y deben distinguirse de fechas, cifras, citas y hechos documentados.

Cuando una publicación trate regímenes autoritarios, guerras o violencia política, el diseño debe mantener suficiente contexto para mostrar consecuencias, víctimas, represión, conflicto y/o resultados históricos cuando sean relevantes.

## 7. Uso de aliases

Un alias visible como `GENERAL ROJO` puede utilizarse como recurso de ficción o diseño. Si existe una referencia histórica real detrás del personaje, la identificación y el contexto deben aparecer en la documentación editorial correspondiente. Los aliases **no** deben utilizarse para ocultar deliberadamente la naturaleza histórica del contenido ni para eludir normas de plataformas.
