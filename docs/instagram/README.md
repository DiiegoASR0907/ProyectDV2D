## Sistema de marca

**Marca:** `HISTORIA EN PIXEL`

**Series principales:** `FICHA JUGABLE`, `CAMPAIGN MAP`, `DICTATORS ARENA`, `HISTORIA COMO MAPA` y `ARCHIVO / CONTEXTO`.

La marca usa una gramática visual de videojuego de estrategia/RPG —HUD, pixel art, stats y mapas— para explicar historia. La estética es una capa narrativa; los hechos, fechas, cifras y consecuencias se documentan por separado.

## Criterio editorial

La estética puede representar figuras, conflictos y sistemas históricos como si fueran elementos de un videojuego. Los nombres ficticios/aliases se consideran un recurso creativo explícito, no un mecanismo para eludir reglas de plataformas. Cuando el contenido se base en hechos históricos, se debe conservar el contexto suficiente para no convertir la representación visual en glorificación o propaganda.

Las estadísticas de videojuego son **interpretaciones editoriales**, salvo que se indiquen explícitamente como datos históricos medidos o documentados.
