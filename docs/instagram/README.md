## Criterio editorial

La estética puede representar figuras, conflictos y sistemas históricos como si fueran elementos de un videojuego. Los nombres ficticios/aliases se consideran un recurso creativo explícito, no un mecanismo para eludir reglas de plataformas. Cuando el contenido se base en hechos históricos, se debe conservar el contexto suficiente para no convertir la representación visual en glorificación o propaganda.
