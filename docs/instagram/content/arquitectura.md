# HISTORIA EN PIXEL — arquitectura de contenido

| Pilar | Objetivo | Assets iniciales |

## 2. Series principales

### FICHA JUGABLE

Formato: 5–7 slides.

1. Portada / personaje.
2. Contexto histórico.
3. Stats editoriales.
4. Facción, unidades o recursos.
5. Decisiones clave.
6. Consecuencias.
7. Fuentes / cierre.

Base visual: HP-001, HP-002, HP-005, HP-014, HP-015.

### CAMPAIGN MAP

Formato: 4–6 slides.

1. Estado inicial del mapa.
2. Primer cambio territorial.
3. Punto de inflexión.
4. Resultado.
5. Contexto y consecuencias.

Base visual: HP-009 y HP-012.

### DICTATORS ARENA

Serie de ficción editorial con estructura de selección de videojuego.

1. Roster.
2. Ficha individual.
3. Stats interpretativos.
4. Habilidades/recursos como metáforas.
5. Hechos históricos que explican el resultado.

Base visual: HP-003 y HP-016.

Regla: la capa de videojuego nunca sustituye el contexto histórico.

### ARCHIVO / CONTEXTO

Posts más documentales para equilibrar el feed.

- Línea de tiempo.
- Definición de conceptos.
- "Qué ocurrió después".
- Mapa explicado.
- Fuente histórica destacada.

## 3. Mix recomendado del feed

Para una primera etapa de 20 publicaciones:

- 30% Personajes / fichas.
- 25% Batallas y campañas.
- 20% Mapas.
- 15% Sistemas y contexto.
- 10% Branding / comunidad / roster.

Esto evita que la cuenta se convierta exclusivamente en una galería de retratos.

## 4. Embudo de contenido

`HOOK VISUAL` → `DATO` → `MECÁNICA DE JUEGO` → `CONTEXTO` → `CONSECUENCIA` → `CTA`

El primer slide debe funcionar incluso sin leer el caption. Los slides intermedios aportan la explicación y el último deja una razón para guardar o comentar.

## 5. Reutilización

Un asset base debería generar una familia de contenidos.

Ejemplo:

`HP-014` → ficha → stats → reel de selección → mapa asociado → carrusel de contexto → story/encuesta.

Objetivo operativo: **1 asset visual = 3–6 piezas editoriales**, no una sola publicación.

## 6. Jerarquía de información

1. Hecho histórico.
2. Interpretación editorial.
3. Metáfora de videojuego.
4. Decoración visual.

Si hay conflicto entre estética y claridad histórica, gana la claridad.
