## Plantilla de producción

Cada publicación nueva debe registrar:

```text
ID:
Serie:
Tema:
Asset(s):
Hecho histórico central:
Interpretación de videojuego:
Hook:
CTA:
Caption:
Fuentes:
Estado: idea / guion / diseño / revisión / programado / publicado
```

## Estados

`IDEA` → `GUION` → `DISEÑO` → `REVISIÓN` → `PROGRAMADO` → `PUBLICADO`

No marcar como `PUBLICADO` hasta tener caption, fuentes y revisión editorial.

## Sistema de numeración

- Assets: `HP-001` … `HP-017`.
- Series: nombres legibles (`FICHA JUGABLE`, `CAMPAIGN MAP`, etc.).
- Publicaciones: `YYYY-MM-SERIE-###` cuando sea necesario para producción.

## Prioridad de reutilización

**Nivel A — plantillas:** HP-001, HP-002, HP-005, HP-010.

**Nivel B — piezas publicables:** HP-004, HP-006, HP-008, HP-009, HP-011, HP-012, HP-014, HP-015.

**Nivel C — conceptos/branding:** HP-003, HP-007, HP-013, HP-016, HP-017.

Los niveles indican prioridad operativa, no calidad artística.
